Term vs cycle changes how each is read. Email, WhatsApp and push are one pot for the year: read actuals from 15 Aug and project forward. Profiles, custom events and embedded messaging reset every 15th–14th and are read one cycle at a time — each is billed on its own peak, so a range spanning two cycles tells you nothing about either.

Sandbox counts against the same allowances, so every figure here understates the bill. Allowance can be added mid-term with 30 days' notice but never reduced. Everything ends 14 Aug 2027 and does not auto-renew. A profile is any email address in the account, so a second project duplicating profiles counts them twice against the same 39M ceiling.
